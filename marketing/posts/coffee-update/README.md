# جوالك يحتاج تحديث قهوة — "Your phone needs a coffee update"

7-slide Arabic carousel, 1080×1350, `export/slide-1..7.png`. Idea from the Pinterest "phone UI × coffee" trend
(`../moodboard-phone-ui.jpg`): each slide is one familiar phone screen that lands on a BrewMaps feature.

| # | Phone screen | Copy | Feature |

| 1 | Software update | جوالك يحتاج تحديث. / تحديث القهوة · حدّث الحين | Hook |
| 2 | Low battery alert | طاقتك ٤٪ · نلقى لك كوفي قريب؟ [دوّر] [مو الحين] | Find |
| 3 | Nearby share | قريب منك · كوفي قريب منك يبي يشاركك فلات وايت. [قبول] [رفض] | Discover |
